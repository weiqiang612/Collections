# 数据库设计 (Database Schema)

## 1. 建表基线与设计原则 (Conventions)
本作品集网站是一套**纯前端 Vue SPA 项目，不依赖底层物理关系型数据库**。
- **静态数据模型**：全部静态结构化数据以 JS 对象字面量保存在 [i18n.js](file:///d:/project/Collection/src/data/i18n.js) 中。
- **本地存储持久化**：用户选择的语言偏好使用浏览器本地存储 `localStorage` 进行持久化，键名定义为 `locale`。
