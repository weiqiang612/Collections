# 原型与 UI 设计 (UI/UX Mockups)

## 1. 交互原型与 UI 视觉稿链接 (Figma / Mockup Links)
- **原型基调**：极客黑色终端风（Minimalist Dark + Geek Terminal），基于 Vanilla CSS，不使用 TailwindCSS。
- **配色系统**：
  *   Background: `#000000` (背景纯黑)
  *   Panel: `#0B0F14` (卡片/控制台面板)
  *   Cyan: `#8BE9FD` (青色高亮/标题/标签)
  *   Green: `#50FA7B` (绿色终端风/呼吸灯/命令行)
  *   Orange: `#FFB86C` (橙色外部链接/警告)

## 2. 核心交互流程
- **打字机终端交互**：首页 Hero 区展示虚拟命令行，流式输入个人技术宣言。
- **项目轮播卡片带**：项目区采用带箭头控制的横向 Case Strip。默认完整展示“主卡 + 下一张卡”，第三张项目以更暗、更窄的阴影预告态露出一部分，提示仍有后续内容。主卡承担进入详情动作，后两张卡承担切换焦点的作用。卡片内部按“编号 / 标题 / 价值定位 / 精简亮点 / 技术标签 / CTA”组织，hover 时有轻微上浮与边框发光反馈。首页卡片正文不做硬截断，改由轮播外层根据全部轮播状态预先测量并锁定稳定高度，避免切换时页面跳动。
- **智能 Agent 弹出层**：点击右下角按钮弹出独立悬浮聊天面板。
- **项目详情页 (Project Detail Page)**：
  * **布局与视觉**：项目详情页首屏采用“内容优先”的上下分栏，先展示 Tagline、成果条、技术标签与关键指标网格，再在下一行展开统一媒体模块。该媒体模块保持相同外壳，但允许项目以视频预留态、脚本化手机演示、截图说明卡或静态产品证明等方式承载内容；其中《餐饮场景 AI 智能客服 Agent 平台》优先使用整行展开的单机位手机轮播演示，替代“建议放视频”的占位态。
  * **内容组织**：中部先展示“项目定位与业务背景”及证明卡片，再展示“系统架构与核心工作流”（Mermaid 交互区域）；当项目具备真实产品界面素材时，在技术图后追加“产品界面与交互证明”截图区，补足产品落地视角。对于《餐饮场景 AI 智能客服 Agent 平台》，能串起“推荐 -> 选菜 -> 加购 -> 取消确认 -> 取消成功”的连续截图链路应优先上收至 Hero 媒体区，正文不再重复平铺同一批图片；底部为“我的职责”（List 结构）与“项目复盘”（Problem-Solution 对照）。
  * **动效与交互**：页面左上角提供悬浮的“Back to Home”按钮（带有 hover 青色微发光及向左平移 3px 动画）；详情页内的 Mermaid 组件完全支持与首页相同的平移、缩放和全屏能力。
