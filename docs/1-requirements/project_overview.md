# 项目说明 (Project Overview)

## 1. 项目背景 (Background)
为了全面、生动地展示开发者的个人技术栈、后端架构设计经验、高并发优化方案以及 AI 工程实践深度，特构建该个人作品集（Portfolio）网站。该作品集不仅是静态简历，更是一个带有交互式系统架构图（Mermaid）及简历智能 Agent 对话的高端极客平台。

## 2. 总体建设目标 (Goals)
- **多语言支持**：实现中英双语界面，满足全球化的内容展示。
- **可解释架构呈现**：利用高可读性的双栏排版与 Mermaid 图表展示复杂后端的执行路径和设计决策。
- **简历智能 Agent 交互**：内置大模型智能客服，允许招聘方通过对话交互式提问开发者的项目细节和工作背景。
- **高性能与极简设计**：前端采用极简黑色极客终端风（Minimalist Dark + Geek Terminal），页面交互流畅，动效丝滑。

## 3. 核心业务大盘 (Core Business Context)
作品集包括以下三个核心展示部分：
- **Hero & About 引导层**：使用终端打字机效果自我介绍，呈现个人后端核心方法论（Why、What、How、Deep Dive）。
- **Project 预览层 + 详情页体系**：首页以四张轻量预览卡片展示《餐饮场景 AI 智能客服 Agent 平台》(Spring AI / RAG)、《高并发本地生活交易平台》(Redis 高并发)、《企业设备资产管理系统》(Spring Boot / 数据治理) 和《Personal CRM 智能联系人管理平台》(Vue 3 / Spring Boot / Agent) 四个代表性项目，先突出项目定位、关键亮点、技术栈和进入详情的 CTA，避免在首页直接堆叠大体量架构图。每个项目均拥有专属的「项目详情页」，用于承载统一结构的 Hero 媒体区、核心指标、Mermaid 图、职责范围和技术复盘内容。
- **Resume Agent 对话面板**：基于 WebSocket / API 的智能聊天窗口，模拟流式/实时 LLM 回答用户提问。
