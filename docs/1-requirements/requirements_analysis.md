# 需求分析 (Requirements Analysis)

## 1. 业务场景描述 (Scenarios)
- 场景 A：面试官或访客进入网站首页，通过打字机引导了解开发者画像，快速浏览顶部核心技术关注点。
- 场景 B：访客滑动到项目展示区，可以通过顶部的极客控制台选项卡（Console Tabs）在《苍穹外卖》、《黑马点评》与《企业设备资产管理系统》三个项目之间自由切换，切换时卡片执行平滑的滑动和渐变过渡动画。在选中的项目下，访客可以切换查阅不同的 Mermaid 交互式图表（如架构图、时序图、ER图），并支持对其进行平移、放大、缩小与全屏缩放。
- 场景 C：访客点击右下角浮动的“简历 Agent”图标，弹出聊天控制台。输入关于开发者项目或经历的问题，系统会以打字机流式输出回复，附带推荐问题引导。

## 2. 用户角色与用例 (User Roles & Use Cases)
| 角色名称 | 职责描述 | 核心用例 |
|----------|----------|----------|
| 面试官 / 访客 | 查阅简历、评估能力 | 切换项目卡片、缩放 Mermaid 架构图、与简历 Agent 模拟对话、查看外部笔记 |
| 开发者 (Ethan) | 简历内容维护与构建 | 扩展静态 JS 国际化配置数据、优化前端交互样式、配置 API 代理 |

## 3. 系统核心业务流 (Core Business Flow)
- **多语言流**：路由/本地存储检测语言（zh-CN/en-US） -> 加载 i18n 对应的静态数据对象 -> Vue 响应式渲染整个 App 视图。
- **Agent 对话流**：用户输入 -> `useChatMock` 判断是否配置后端 API ->
  - 若未配置：从 `i18n.js` 中的 `mockReplies` 里随机抽取内容，以字符逐个reveal的方式流式输出。
  - 若配置：发起 POST 请求至 `/api/chat` 并读取回复渲染。
